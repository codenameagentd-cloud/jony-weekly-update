Template Gallery v2

10 directions inspired by recent Design Diary entries. Each one is a different structural system — not a color swap.

01. Type Material
← BLUR (Behance)
Typography IS the visual. Serif display + outlined strokes. Borders dissolve between decoration and information.
02. Silent Whisper
← Silent House (Awwwards)
Dark, ultra-light weight, centered. Whisper in a room of shouting. Cormorant Garamond at 300.
03. Noise Paper
← Lost Memories (minimal.gallery)
SVG noise texture, handwritten headings, analog warmth. Content as found artifact.
04. Exhibition
← Terraform (Behance)
Dark burnt earth tones, gold accent. Emotional, gallery-like. Playfair Display serif weight.
05. Electric
← The Push (Awwwards)
Full-bleed electric blue cover, flips to dark content pages. Underground energy, bold uppercase.
06. Linen
← Kindred of Ireland (Awwwards)
Warm off-white, Lora serif, minimal dividers. Material honesty — like unbleached fabric.
07. Mural
← Fetco Mural (Dribbble)
Deep teal + amber + ocean blue. Color from place × product. Fraunces serif, ornamental dots.
08. Swiss
← Müller-Brockmann grid system
Pure 6-column grid, red accent block, Inter 800. Content-sidebar split. Zero decoration.
09. Dissolve
← BLUR philosophy
Gradient background, glass-morphism cards, text fades from white to transparent. Boundaries blur.
10. Dual View
← The Push "Change View"
Split-screen: dark left (title) + light right (content). Alternates between split and full-dark layouts.
