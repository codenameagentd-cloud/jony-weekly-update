# 設計技巧庫

## Image Generation / AI Art

### Prompt 一句話原則
- 每張圖先定核心：「這張圖要傳達的一句話是什麼」
- 寫不出一句話 = 還沒想清楚，不要動手
- 元素有主角配角之分，不要平均撒

### 風格適配
- Maximalist（cyberpunk/baroque）→ 過載是語言，不要克制
- Minimalist（Swiss/Japanese）→ 每個元素都要有理由
- 先吃透風格本質，再加個人判斷

### 從感覺出發 vs 從樣子出發
- 畫抽象概念時，先問「這個人/東西給人什麼感覺」
- 再把感覺翻譯成視覺元素
- 範例：「可靠」→ 不是畫一個強壯的人，是畫黑暗中一條不會斷的白線

## Roasted.cc — 設計拆解 (2026-03-15)
**來源**: https://roasted.cc | Godly featured

### 構圖技巧

**1. 全幅英雄區 + 產品攝影作為主角**
- Hero section 讓產品攝影（咖啡袋、咖啡杯）佔滿視窗
- 不加多餘 UI 元素，讓攝影本身說話
- 適用場景：任何有強視覺素材的品牌頁

**2. 暗色調 + 暖色對比**
- 深棕/黑色基底 + 暖橘/金色文字和按鈕
- 色彩直接呼應產品（咖啡 = 深烘焙色）
- 技巧：品牌色不是隨便挑的，從產品本身提取

**3. 大字型 + 極少量正文**
- 標題用超大 serif/display 字體（可能 100px+）
- 正文極短，每段不超過 2-3 行
- 原則：讓人掃讀，不讓人閱讀。每個 section 只傳達一個訊息

**4. 垂直節奏 — 滿-空-滿交替**
- 全幅圖片 → 大留白文字區 → 全幅圖片
- 這種交替創造呼吸感，防止視覺疲勞
- 留白不是空，是設計的一部分

**5. 攝影風格統一 = 品牌一致性**
- 所有產品照片同一光源方向、同一色溫、同一後製風格
- 即使換場景（桌面、手持、包裝），質感統一
- 這比 logo 更能建立品牌認知

**6. 滾動驅動的敘事結構**
- 不是「頁面」，是一個「故事」：品牌 → 產品 → 細節 → 購買
- 每次滾動揭示新資訊，維持好奇心
- 動效服務於敘事（淡入、parallax），不是裝飾

**7. CTA 克制**
- 整頁可能只有 1-2 個明確的行動按鈕
- 不急著賣，先建立情感連結
- 按鈕風格融入整體設計（不突兀、不花俏）

### 可直接應用的技巧
- **Status report**: 暗色調 + 暖色 accent 的色彩邏輯（neon template 已經在用）
- **模板設計**: 滿-空-滿的垂直節奏可以用在 slide 之間的過渡感
- **任何品牌頁**: 攝影統一 > logo 統一，色彩從產品提取
