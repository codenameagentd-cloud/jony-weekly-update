# Design Diary 洞察集

從每日設計日記中提煉的可複用知識。

---

## 待補充
（每篇 diary 完成後在這裡追加 1-3 個具體技巧）

### 格式範例：
### [Antinomy Studio] 空間即信息
- **技巧**：用大面積留白暗示高端定位，不靠文字說明
- **做法**：section 間距 > 150px，hero 高度 100vh 只放一行字
- **為什麼有效**：留白是一種「我不需要塞滿來證明自己的價值」的自信
- **可用場景**：品牌官網、portfolio、高端產品頁

### [all.inn] 系統化的放縱
- **技巧**：用嚴格的設計系統支撐「好玩」的視覺，讓品牌同時可信又有趣
- **做法**：有機形狀用 SVG mask 統一管理、色彩用 CSS custom properties、動畫曲線全站統一 cubic-bezier
- **為什麼有效**：放縱有系統 = 專業的好玩；隨意的放縱 = 業餘的花俏
- **可用場景**：年輕品牌官網、教育平台、共居空間

### [all.inn] 色彩身份替代文字標籤
- **技巧**：每個分類/房型給予獨立色彩 identity，不靠文字就能區分
- **做法**：4-6 個高飽和色 + 統一的中性底色（cream 系），每色只對應一個語義
- **為什麼有效**：色彩辨識速度比文字快 60,000 倍（MIT 研究），減少認知負擔
- **可用場景**：多品類產品頁、分類導航、dashboard tags

### [Shopify Renaissance Edition] 文化框架法
- **技巧**：用一個強文化隱喻（文藝復興）統一大量異質內容的視覺語言
- **做法**：選定文化主題 → 提取色彩（暖金/深棕）、材質（油畫紋理）、排版（serif/古典比例）→ 所有內容都通過這個框架呈現
- **為什麼有效**：文化框架給人「經歷旅程」的感覺，而不是「消費列表」
- **可用場景**：產品 changelog、年度報告、大型活動 landing page

### [Shopify Renaissance Edition] 情緒先行轉場
- **技巧**：先用藝術/情緒元素建立氛圍，再從中揭露功能/資訊元素
- **做法**：油畫紋理 → fade/reveal → 產品截圖，時序上情緒先於資訊
- **為什麼有效**：讓觀者在「理解」之前先「感受」，降低資訊抗拒
- **可用場景**：功能展示頁、product launch、onboarding flow

### [Incomplete Glossary of Time] 命名即設計
- **技巧**：先為無名的體驗造詞，再圍繞這個詞設計整個交互
- **做法**：用 AI 生成有拉丁/希臘詞根的新詞 → 配上定義和詞性 → 用辭典的視覺語言（serif、邊框卡片、翻頁隱喻）呈現
- **為什麼有效**：語言塑造認知——一旦體驗有了名字，它就從模糊感受變成可設計的對象
- **可用場景**：設計系統文件（為未命名 pattern 造詞）、UX 研究報告、情緒化產品

### [Incomplete Glossary of Time] 單一功能色
- **技巧**：全站只使用一個彩色，讓它承載 100% 的語義重量
- **做法**：中性底色（cream/white）+ 黑色文字 + 唯一彩色只出現在特定功能位置（如詞性標記）
- **為什麼有效**：當只有一個顏色時，眼睛會自動追蹤它，等於免費的視覺引導
- **可用場景**：文件型網站、editorial design、任何需要極度克制的設計

### [THE GRIND] 材質覆蓋層即品牌身份
- **技巧**：用一個統一的材質紋理（如紙板）覆蓋所有影像，讓數位內容獲得實體觸感
- **做法**：半透明 cardboard texture PNG 覆蓋在所有照片上方，混合模式 multiply/overlay
- **為什麼有效**：一層紋理就能讓整站所有影像產生統一的「手作」感，成本極低但品牌識別度極高
- **可用場景**：獨立品牌官網、zine 風格 portfolio、強調「真實」「手作」的品牌

### [THE GRIND] 字重即態度宣言
- **技巧**：用極端字重（condensed black）傳達品牌態度，而非追求可讀性
- **做法**：選一款 condensed 字型推到最粗，字距壓到負值，只用在標題/數字，正文另選輕量字型平衡
- **為什麼有效**：字型的物理重量直接傳達壓力、密度、不妥協——不需要文字內容就能「說話」
- **可用場景**：運動/健身品牌、工業風品牌、任何需要「強硬」氣質的設計

### [Samara] 無色 UI 讓產品帶色
- **技巧**：UI 完全去色（白底黑字灰線），所有色彩由產品攝影的自然材質提供
- **做法**：背景 #fff、文字 #000、分隔線 #e5e5e5，不設 brand color，讓建築攝影裡的木色、混凝土灰、植物綠成為唯一色彩來源
- **為什麼有效**：像白牆美術館——牆不需要顏色，因為作品會說話。UI 退到最後面，產品自然成為焦點
- **可用場景**：任何有強視覺素材的品牌官網、建築/室內設計 portfolio、高端產品頁

### [Samara] 低語式文字系統
- **技巧**：文字不大喊，像美術館作品旁的小牌子——走近了才看到，但每個字都有份量
- **做法**：標題不超大、正文不囉嗦、section 間距 120px+、用留白而非字級創造層次
- **為什麼有效**：奢侈的留白讓每個 section 像走進新房間，而非滾動無盡頁面
- **可用場景**：高端品牌官網、建築/地產（非傳統地產）、lifestyle 產品
