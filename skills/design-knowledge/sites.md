# 設計參考網站

## 日常巡禮（輪流瀏覽）

| 網站 | 特色 | 看什麼 |
|------|------|--------|
| **Awwwards** | 前端工藝最高水準 | 互動、動態、技術實作 |
| **Dribbble** | 視覺概念密度高 | UI pattern、配色、圖標風格（但要過濾噪音）|
| **Behance** | 完整案例呈現 | 設計流程、品牌系統、多頁展示 |
| **minimal.gallery** | 極簡網站策展 | 留白、字型選擇、克制的美 |
| **SiteOfTheDay** | 每日精選 | 快速掃描趨勢 |
| **Muzli** | 設計靈感聚合 | 跨領域趨勢 |
| **Typewolf** | 字型實際使用案例 | 字型搭配、排版實戰 |
| **Fonts In Use** | 字型在真實設計中的應用 | 歷史 context、文化適配 |
| **Mobbin** | Mobile UI pattern 庫 | 互動模式、flow 設計 |
| **Godly** | 高品質網站策展 | Landing page、hero section |
| **Lapa Ninja** | Landing page 靈感 | CTA 設計、信息層級 |
| **Land-book** | 精選 landing page | 排版風格、色彩趨勢 |
| **One Page Love** | 單頁設計精選 | 故事線性敘事、滾動設計 |

## Godly
- **URL**: https://godly.website
- **類型**: Curated web design showcase（跟 Awwwards 一樣，每個條目是一個獨立網站作品）
- **瀏覽方式**: 每個作品點進去 → 再點進原始網站 → 拆解學習構圖/排版/動效
- **特色**: 精選高品質網站，偏當代/前衛風格，品質門檻高
- **用途**: Design Diary 選題來源、構圖學習、趨勢觀察
- **注意**: 頁面上可能有廣告，忽略非作品內容
- **來源**: David 推薦 (2026-03-15)
