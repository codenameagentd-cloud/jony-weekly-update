# Design Knowledge Base

從每日 Design Diary 和設計網站研究中提煉的可複用設計知識。

## 用途
- 做設計決策時快速查閱已知的 pattern 和技巧
- 避免重複犯錯
- 在新項目中快速套用已驗證的方法

## 知識分類

### 參考文件
- `typography.md` — 字型搭配、層級、排版技巧
- `color.md` — 配色理論、已驗證的色彩方案
- `layout.md` — 構圖、Grid、空間系統
- `motion.md` — 動態設計、過渡、微互動
- `brand.md` — 品牌一致性、視覺語言建立
- `techniques.md` — 具體實作技巧（CSS/SVG/Canvas）
- `diary-insights.md` — 從 Design Diary 提煉的設計洞察
- `sites.md` — 設計參考網站清單和各自的特色

## 更新規則
- 每篇 Design Diary 寫完後，提煉 1-3 個具體技巧寫進對應分類
- 每週設計自審時，把新發現的 pattern 歸檔
- 格式：`### [來源] 技巧名稱` + 具體做法 + 為什麼有效
