**David 反饋 & 教訓：**
1. **不要改風格系統** — David 要的是「用這個風格去設計內容」，不是重新設計風格。第一版我自己亂加黑色 panel、split layout，完全偏離原版 brutalist template。
2. **排版要有設計感** — 不是把文字塞進去就叫設計。每頁需要一個視覺焦點（hero element），其他內容退後。
3. **先自審再交付** — David 明確說「你再給我前先自我審查一下再給我，不要那麼草率」。前幾版都是趕著發，沒有真的看過。
4. **對照 reference** — 拿到 reference 要逐項比對（字級、間距、裝飾元素、counter 大小），不能只看大方向。

**設計原則提煉：**
- 原版 template 每頁只有一個焦點：一個 120px 大數字 + 一句話 + 大量留白
- 等權重塞內容 = 沒有設計
- Brutalist 的語言：白底、3px 黑框、Inter 900、Space Mono、#FFD600 highlight、collapsed borders、裝飾空框、slam 動畫
