# Design Diary — 2026.6.29

## Pil Rebranding Site
- **Source:** Awwwards Nominee
- **URL:** https://pilcommunication.com/
- **Awwwards:** https://www.awwwards.com/sites/pil-rebranding-site
- **Agency:** Pil Communication（義大利，20 年品牌代理商）

### 為什麼選這個
在一堆炫技 WebGL 和粒子效果的提名裡，Pil 反其道而行——用克制和留白表達品牌自信。20 年老牌代理商的重建，不是改版，而是設計宣言。

### 設計觀察
1. **留白即自信** — 首頁品牌名佔據視覺中心，大量負空間，不說廢話
2. **影片即結構** — 影片不是裝飾嵌入，而是 section 主體，文字圍繞呼吸
3. **反直覺字重** — 標題用 light weight，正文用 regular，形成張力
4. **漸進式揭露** — 服務區不用 icon grid，用可展開的文字區塊
5. **敘事即展示** — 作品穿插在品牌敘事中，建立信任和展示能力融為一體
6. **克制的 footer** — 沒有 newsletter/CTA 堆疊，只有必要聯繫資訊

### Takeaway
空是選擇，安靜是能力。20 年最大的收穫是學會閉嘴。
