## Pil Rebranding Site
- **URL:** https://pilcommunication.com/

- **Agency:** Pil Communication (Italy, 20 years)
- **Notion:** https://app.notion.com/p/2026-6-26-Pil-Rebranding-Site-38af6af8fd4d815b8dc5e489ceb99ac4

## Key Takeaways
1. **Self-effacing portfolio strategy** — black/white site lets colorful client work shine
2. **Typography confidence** — Bebas Neue + News Cycle (free Google Fonts) elevated by spacing mastery
3. **Non-uniform vertical rhythm** — paragraph spacing as punctuation, not mechanical
4. **Video size modulation** — full-bleed vs. embedded small creates attention rhythm
5. **No UI chrome on hero** — no hamburger, no scroll indicator, no CTA = radical confidence
6. **Passive persuasion** — atmosphere > explicit showcasing for design agencies

## Design Principle Extracted
"Don't use design to convince people you understand design. Let the work, the space, the restraint speak."
