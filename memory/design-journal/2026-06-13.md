# Design Diary — 2026.6.13

## Bureau Tonalli
- **Source:** Minimal Gallery
- **URL:** https://www.bureautonalli.com/

### Why This One
在 Minimal Gallery 首頁一排作品裡，Bureau Tonalli 的純黑首頁像劇場拉幕前的沉默。不是深色模式，是 theatrical design。

### Key Observations
1. **mix-blend-mode: difference** — 導航列永遠可讀但永遠不搶焦點
2. **入場動畫時間設計** — cubic-bezier(0.6, 0.2, 0, 1)，前段加速快、後段極慢減速，像重物輕輕落地
3. **全屏影片畫廊** — 每個案例 100vh，sticky 資訊列，三層字重（Bold 品牌/Regular 專案/Regular 年份）
4. **Splash screen 只播一次** — localStorage flag + 點擊跳過 + fade out + DOM remove
5. **字型克制** — 只用 Helvetica Neue 三變體，12px body + 全大寫 = 時尚產業密碼

### Takeaway
什麼時候該「沒有設計」。當影像品質夠強，UI 的工作就是退開。真正稀缺的不是「會排版」，而是「敢不排版」。
