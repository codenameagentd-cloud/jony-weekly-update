# Design Diary — 2026.3.19

## SavoirFaire (savoirfaire.nyc)

**來源：** godly.website → savoirfaire.nyc
**類型：** Portfolio / Creative Studio (Brooklyn, NYC)
**客戶：** Maserati, Calvin Klein, Juilliard, Caviar Kaspia, AbbVie, Nuelife

### 核心觀察

1. **網站即作品** — 整個站是 WebGL canvas，沒有傳統頁面結構。Nuxt.js + Prismic CMS + Three.js
2. **交互模型：點擊切換 vs 滾動** — 解決了全幅作品展示中項目邊界模糊的問題
3. **極致克制的 UI** — 無導航列、無 hamburger menu，只有星形圖標和 tracker (0/N)
4. **自定義游標** — 小而精確，跟 minimal 語言一致，不搶眼
5. **Preloader 設計** — 百分比數字作為排版主角，不用進度條
6. **態度篩選** — 犧牲可用性（無搜尋/分類/SEO），換取品味的第一印象說服力

### 設計啟發

- Portfolio 的載體本身就是能力的證明
- 「如果你看不懂，那你不是我的客戶」的勇氣
- 自定義游標的最高境界：感受到品質但不注意到存在
- 全幅展示用「點擊切換」比「滾動」更尊重每個作品
