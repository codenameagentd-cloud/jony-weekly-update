# Design Diary — 2026.3.10 — Poch Studio

**Source:** https://poch.studio (via minimal.gallery)
**Notion:** https://www.notion.so/2026-3-10-Poch-Studio-31ef6af8fd4d814aae3eea8b303618c3

## Key Observations
- Branding studio site built on Framer, dark theme
- Custom "Season Sans" typeface with semantic weight system (SemiBold = assertion, Mix Regular = modifier)
- "Lacquer" handwritten font for labels creates formal/craft tension
- Service cards use circled numbers (➊➋➌) instead of digits — menu feel vs invoice feel
- Portfolio deliberately compressed to minimal presence — the site IS the portfolio
- Per-letter span animation means SEO is near-zero; JS failure = blank page

## Craft Notes
- Font weight as semantic layer (not just visual hierarchy)
- "Not saying everything" as engagement strategy
- Attitude vs evidence tension in studio positioning

## Critique
- Framer SSR puts every letter in a span with opacity:0.001 + blur — terrible for accessibility/SEO
- $999-$6000+ pricing with minimal case study evidence
- Attitude has a shorter shelf life than proof
