# Design Diary — 2026-04-07

## piet.page (Piet Terheyden)
- **Source:** minimal.gallery
- **Why:** Minimal Gallery 創辦人的個人網站，十三年策展審美的結晶
- **Key takeaways:**
  - max-w-xl (576px) 單欄佈局，大螢幕上內容只佔 1/3，留白即姿態
  - Pretendard 字體，letter-spacing: -0.011em，三個字重（400/500/600）
  - 層級靠透明度：text-subtle = foreground 85% opacity，不靠字級跳躍
  - 色彩系統：純 HSL 灰階，0 0% 變體，zero chromatic pixels
  - elegant-link：gradient 虛線底線 + dash-move keyframe 1.5s，全站唯一動態
  - 64×64 圓形頭像，ring-1 ring-border，300ms opacity transition
  - 兩層間距：space-y-16（區塊間）+ space-y-5（段落間）
  - 用 Lovable (AI builder) + React + Tailwind 生成，工具不重要，判斷力才重要
- **Core insight:** 看得夠多以後你就不再害怕簡單。策展人的最佳副產品——你終於敢什麼都不做了
