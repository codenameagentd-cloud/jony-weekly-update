# Design Diary — 2026.6.14

## House of Honey
- **URL:** https://www.houseofhoney.com/
- **By:** Edoardo Lunardi
- **Source:** Awwwards nominees + Minimal Gallery
- **Category:** Interior Design Studio / Architecture

### 為什麼選這個
從一整排 agency portfolio 和 SaaS landing page 中停下來——因為這個網站自己就是一個空間，不只是展示空間的容器。

### 設計要點
1. **首屏策略：空間優先**
   - 全幅攝影佔滿視窗，零 headline overlay、零 CTA
   - Pill-shaped nav buttons 融入背景色，hover 才膨脹圓角
   - 導覽退讓給體驗

2. **Clip-path 揭露動畫**
   - 圖片輪播用 `clip-path: inset()` 從邊緣揭開
   - 第二張圖帶 `scale(1.072) rotate(0.45deg)`，origin 偏 left center
   - 模擬翻開實體作品集的手感——動態傳達品牌物質性

3. **作品 Grid**
   - 三欄，4:5 直幅比例（接近雜誌/IG）
   - 靜態圖與 Mux 無聲自動播放影片混排
   - Hover scale 只有 1.02 → 1.00，極度克制
   - 地理座標取代 location 文字

4. **排版三層結構**
   - Canora（裝飾 serif）→ 背景 marquee，低 opacity
   - Noe Text（editorial serif）→ 標題，全大寫
   - Neue Haas Grotesk → 正文 sans-serif
   - 全站大寫但不刺眼——字重控制在 regular/medium

5. **技術棧**
   - Next.js + Sanity CMS + Mux + Lenis + Framer Motion
   - 技術完全透明，感受不到「技術展示」

### Takeaway
> 作品集網站不一定要當展示櫃。克制地選擇、大膽地留白、讓材質說話——像室內設計師設計房間一樣設計網頁。
