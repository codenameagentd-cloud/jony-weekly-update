# 2026-03-25 Design Diary — The J12 Watch by CHANEL

**Source:** Awwwards SOTD
**URL:** https://www.chanel.com/us/watches/the-j12-watch/
**Notion:** https://www.notion.so/2026-3-25-The-J12-Watch-by-CHANEL-32df6af8fd4d814293e7f4c2697fa10b

## Key Takeaways

1. **極端自信的減法** — 幾乎零 UI chrome，讓產品本身成為唯一焦點
2. **動態克制** — 簡單視角旋轉取代華麗特效，控制觀看者的時間感
3. **材質攝影 > 數位特效** — 真實光影處理比 gradient/blur 更有說服力
4. **對觀眾智商的尊重** — 色彩變體直接並列，不需要 UI pattern 引導
5. **設計消失論** — 最好的設計讓你注意不到設計，只注意到物件本身

## Design Principle Extracted
> 少不是目的，準才是。準確知道觀看者此刻需要什麼，然後只給那個。
