# 2026-06-27 Design Diary — Pil Rebranding Site

**Source:** Awwwards SOTD Nominee (June 2026)
**URL:** https://pilcommunication.com/
**Tech:** React, Three.js, Tailwind, TypeScript
**Fonts:** Bebas Neue + News Cycle (Google Fonts)

## Why This One

Agency 網站通常落入「過度表演」的陷阱。Pil 反其道而行——用結構和字型的力量說話，留白成為最大聲的設計語言。

## Key Takeaways

1. **兩套字型解決一切** — Bebas Neue (condensed/geometric/display) + News Cycle (neutral/readable/body)。對比度本身就是層級。
2. **3D 作為唯一色彩載體** — 整站黑白灰，幾何體帶唯一飽和色 = 絕對焦點
3. **克制的互動** — Three.js 物件跟隨游標微旋轉，振幅壓在「活的但不是在跳舞」的區間
4. **轉場 = opacity + translateY** — 不超過 300ms，不用 page transition library，組件級控制
5. **Footer 作為品牌宣言** — 反轉色彩（黑底白字）+ 超大字級 = 首尾呼應

## Design Principle Extracted

> 最難的設計不是做加法，而是在有能力做加法的時候選擇不做。

Agency 網站該是作品集還是品牌宣言？Pil 選了後者——視覺語言本身就是最好的案例。
