# Design Diary — 2026.5.31

## The Kesey Signal
- **Source:** Awwwards Nominee
- **URL:** https://thekeseysignal.com/
- **By:** Rob Ford
- **Key Insight:** 受限設計（Constrained Design）的極致——整個瀏覽器變成 1999 CRT 終端機，用掃描線 CSS overlay + Courier Prime monospace 重建磷光管物理感
- **Design Lesson:** craft 不一定是像素級打磨，也可以是選擇性捨棄。用最少視覺手段創造最強物理感
- **Technique:** CSS linear-gradient 4px scanlines, overflow:hidden 全頁終端模擬, monospace-only typography hierarchy
