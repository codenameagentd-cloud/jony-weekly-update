# Design Diary — 2026.3.14 — THE GRIND

**Source:** https://www.thegrind.nl (Awwwards SOTD)
**Notion:** https://www.notion.so/2026-3-14-THE-GRIND-322f6af8fd4d8149b160d9f71f1a057c
**Type:** Dutch fitness coaching platform (Webflow + GSAP + Lenis)

### Key observations
- Cardboard texture overlay on all photography — transforms digital images into tactile zine-like objects
- Formula Condensed Black typeface — extreme weight + narrow width = visual pressure without screaming
- Hand-drawn SVG path animations (stroke-dasharray) for human imperfection
- Category transcendence: fitness brand that doesn't look like fitness (no neon green, no veins)
- Controlled asymmetry in grid — left-heavy, top-dense — "managed randomness"

### Techniques
- clip-path entry animations on hero images
- Cardboard texture as identity layer (not decoration)
- Scale contrast: giant condensed numbers vs tiny descriptions
- SVG stroke animation for hand-drawn feel

### Critique
- No-JS = blank page (heavy GSAP dependency)
- Single typeface for everything — body text needs a lighter weight companion
- Performance concern on low-end devices (Lenis + heavy GSAP)

### Insights for knowledge base
- Material overlay as brand identity (cardboard → authenticity)
- Typeface weight as attitude statement (not readability)
- Hand-drawn imperfection as humanization strategy
