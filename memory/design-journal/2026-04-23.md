# Design Diary — 2026.4.23

## Ruinart Digital Fresco
- **Source:** Awwwards SOTD
- **URL:** https://fresque.ruinart.com
- **Awwwards:** https://www.awwwards.com/sites/ruinart-digital-fresco
- **Notion:** https://www.notion.so/2026-4-23-Ruinart-Digital-Fresco-34af6af8fd4d8115bb4fc691762f2f05

### Key Takeaways
- 色彩克制：暖金 + 深黑雙色溫，沒有多餘 UI 裝飾
- 互動模式：水平滾動模擬酒窖行走，「原地深入」展開敘事層而非跳轉
- Typography：襯線體呼應古典，字重行距現代化
- 核心洞察：數位不是實體的替代品，是新維度。問「線上能給什麼實體給不了的」而非「怎麼搬到線上」
