## 為什麼選這個

Speculative design project 偽裝成秘密組織的品牌網站。全站無 WebGL/Three.js，所有動態效果（spotlight mask、scroll-driven animation、百葉窗轉場）都用純 CSS 實現。Nuxt 架構。

## 設計重點

- **純 CSS 動態引擎**：CSS @property 自訂 --spotlight-angle/--spotlight-distance，配合 mask-image 做石頭的即時光影。兩層 hover texture 疊加模擬黑曜石光澤
- **材料驅動的色彩系統**：四色（#151415 近黑、#f1eade 暖奶黃、#7b5136 古銅棕、#242324 石灰）全部來自黑曜石的色譜
- **三套字型的張力**：OTJubilee-Platinum（金屬感標題）+ Voyage-Regular（古典大字）+ Switzer（中性內文）
- **文字入場用 --char-random 而非 --char-index**：字母隨機浮現而非依序出現
- **單一主斷點（1024px）**：layout 只做一次 responsive，其餘靠字型縮放
- **Grid 定位透過 CSS custom properties**：--left/--top/--width/--height 直接控制
- **語言設計即 UX**：Sign Up → Seek Admission、Locations → Places、「You Won't Find Them on a Map」

## 延伸思考

Design fiction 在網頁領域的實踐——設計一個「不想被找到」的數位存在。排他性不需要高價商品，只需要完全不妥協的設計語言。
