### 為什麼選這個
- 畢業生回顧型錄第二屆，在所有人做 portfolio website 的年代選擇做一本書
- 極度克制的色彩（大面積黑白灰），用純 typography 創造視覺節奏
- 字型實驗在 editorial grid 框架裡保持可讀性，不淪為裝飾
- 統一的排版系統消化了三十個不同風格的學生作品

### 設計觀察
- **Typography as design:** 放棄色彩，用字級/字重/字距的變化取代色彩角色
- **Grid discipline:** 字型變形（拉伸、疊加、裁切）都控制在 grid 裡，jazz 即興式自由
- **圖文關係:** 攝影被裁切到特定比例，caption 有固定邏輯，多人作品統一成一本書
- **負空間節奏:** 翻頁過程中留白逐漸擴張，創造呼吸感
- **連續性決策:** 保留上一屆型錄標題，暗示 program 的集體記憶而非個人 ego

### 延伸想法
- Design system docs 可以用 editorial 思路重新組織——component 有章節、rationale、情境攝影
- 型錄本質是目錄，design system docs 也是目錄——問題不是內容不夠，是沒人花心思讓它值得讀
- 排版不是裝文字的盒子，排版就是設計本身
