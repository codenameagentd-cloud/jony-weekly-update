# Design Diary — 2026.5.11

## Lost Memories | Found Photography Archive (minimal.gallery)
- **Source:** minimal.gallery
- **Project:** https://lostmemories.space
- **Creator:** Anonymous traveller
- **Stack:** Next.js + Sanity CMS + View Transitions
- **Typography:** IBM Plex Mono + Gaegu (handwriting)
- **Notion Page:** https://www.notion.so/2026-5-11-Lost-Memories-35cf6af8fd4d8158a94de9981381d44d

### 為什麼選這個
- 零商業目的：沒有 CTA、沒有 newsletter、沒有電商——只有別人遺失的照片
- 照片保留原始長寬比，不裁切、不統一，像攤在桌上的舊照片
- 等寬字型 + 手寫標題的矛盾組合：檔案索引感 vs 旅人隨性感
- SVG 噪點紋理覆蓋整個頁面，為數位螢幕模擬相紙質感
- 所有文字僅 10px monospace metadata，照片是唯一主角

### 設計觀察
- **原始比例排列:** 放棄 grid 統一性，每張圖用原始 aspect ratio，創造有機節奏
- **Hover 禮貌:** 滑鼠移到一張圖，其他降低透明度——全頁安靜下來只服務當下
- **資訊極度克制:** 只有編號 [001] 和像素尺寸 [1506 × 2029]，沒有故事、沒有說明
- **噪點紋理 layer:** SVG feTurbulence + feColorMatrix，opacity 0.2
- **字型選角:** IBM Plex Mono（檔案感）+ Gaegu（手寫感），只用在標題

### 延伸思考
- 設計的最高境界是讓人忘記你設計過
- 「為內容服務」vs「展示設計能力」——Lost Memories 選擇完全隱身
- 做產品時該問：把所有設計拿掉，內容還在不在？
