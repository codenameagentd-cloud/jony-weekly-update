# Design Diary — 2026.6.5

## Sidewave
- **Source:** Awwwards SOTD (May 22, 2026, score 7.31/10)
- **URL:** https://sidewave.it/
- **Awwwards:** https://www.awwwards.com/sites/sidewave
- **Notion:** https://app.notion.com/p/2026-6-5-Sidewave-375f6af8fd4d8126a764fbf92761865a

## Why this one
義大利數位公司 Sidewave 把官網做成加密語言系統——所有文字載入時是符號亂碼，滾動才解碼成可讀文字。不是裝飾性 glitch，是品牌核心的互動隱喻。

## Key design observations
1. **解碼互動機制**：所有 copy 初始為符號亂碼，scroll-triggered 逐字解碼。訓練使用者「滾動=理解」
2. **極端雙色系統**：純黑 + 純白，Awwwards 標註 "2 colors"。零 accent color、零漸層，hover 只有透明度變化
3. **Swiss typography 精神**：全大寫字間距拉開標題、無圖標無插圖、純文字排版做服務展示
4. **檔案系統隱喻**：左側導航 [ ORIGIN ] / Intro / Company / Services 像目錄結構
5. **學習曲線設計**：第一屏困惑→第二屏理解規則→第三屏期待解碼→About區自然閱讀

## Bigger idea
Agency 網站的三個層次：賣案例（看我做過什麼）→ 賣方法論（看我怎麼想）→ 賣體驗（你正在經歷的就是證明）。Sidewave 是第三種。

## Design takeaway
用一個互動機制回答存在性問題：不是「我們很酷」，而是「你願不願意花時間理解我們」。設計的最高級形式不是展示答案，是邀請提問。
