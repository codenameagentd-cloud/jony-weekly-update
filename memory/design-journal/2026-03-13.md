# Design Diary — 2026.3.13

## Springs (springs.estate)

**Source:** Awwwards SOTD
**Type:** Wellness residences, luxury real estate
**Built with:** Custom (heavy parallax, sticky sections)
**Why:** Can a real estate site not look like a real estate site?

### Key observations
- Scattered text hero — words as spatial composition elements, not standard centered headline
- Parallax at 0.7x speed — minimal but creates "through the window" depth
- Meditative vocabulary — "essence", "contemplation", "renewal" instead of "luxury"
- Nature > Architecture — buildings recede, landscape dominates
- 120px+ spacing between text blocks — the page breathes

### Critique
- 27000px page height, stuttery parallax on mid-range devices
- Practical info (floor plans, pricing, timeline) buried under atmosphere
- Aesthetic vs function balance not resolved

### Go wild
- Sound-only real estate site: wind, water, footsteps on wood. Eyes closed walkthrough.
- Adaptive content based on browse time: 30s = hero + phone number, 3min+ = deep details
- 24h real-time rendering: morning light, sunset shadows, city lights at night via Three.js + weather API
