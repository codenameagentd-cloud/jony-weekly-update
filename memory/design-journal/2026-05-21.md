# Design Diary — 2026.5.21

## What Color Was The Sky (Awwwards)
- **Source**: https://sinceyouarrived.world/sky
- **Found via**: Awwwards Nominees (May 2026)
- **Creator**: Matt (Since You Arrived series)
- **Type**: Data-driven editorial / atmospheric visualization
- **Tags**: Experimental, Minimal, Typography, Responsive, CSS, HTML5

### Why This One
不是因為動畫厲害或視覺衝擊力強，而是因為它問了一個從來沒被網站問過的問題：昨天你頭頂的天空，是什麼顏色的？用真實氣象數據重建天空漸層，把 API response 的 JSON 變成散文。

### Key Observations
1. **數據文學化**：氣象數據（雲量、濕度、溫度）不是圖表或 dashboard，而是翻譯成散文式自然語言
2. **CSS @property 漸層動畫**：六個色階（zenith/high/mid/low/horizon/glow）用 registered custom properties 做原生插值，1.8s cubic-bezier 過渡
3. **字型搭配說故事**：Fraunces（手寫感襯線）= 感性表面，JetBrains Mono（等寬）= 理性數據骨架
4. **技術極簡 = 視覺極簡**：純 HTML/CSS/JS，零 framework，Open-Meteo 免費 API，Vercel 部署
5. **Zero UI 首屏**：沒有 navbar、hamburger、CTA，只有天空漸層和標題

### Extended Thinking
- 最強的設計工具不是 Figma 或 Framer，是一個足夠好的問題
- 數據視覺化的最高境界可能不是「視覺化」而是「文學化」
- 設計的成功不在於用戶看到了什麼，而在於用戶感受到了什麼
