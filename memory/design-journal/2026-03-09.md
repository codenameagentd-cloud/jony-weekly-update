# Design Diary — 2026.3.9

## Antinomy Studio (antinomy.studio)

**Source:** Awwwards SOTD
**Type:** Global creative studio website (Amsterdam / Berlin / New York)
**Built with:** Nuxt.js, Three.js, WebGL, Lottie
**Clients:** Google, Microsoft, Yuga Labs, MetaMask, i-D

### Why I chose it
最近一直在想：當一個 studio 說自己做「數位體驗」，這句話還有沒有意義？Antinomy 用實際案例證明可以不只是 buzzword — Google Gemini、Yuga Labs、MetaMask 這些專案裡的 craft 是可以被拆解、被學習的。

### Key observations

**導航的標點符號設計**
Home, Projects, About, Careers, Contact. 用逗號隔開，最後是句號。這不是為了可愛，是在說：「這是一句完整的句子，我們提供的就這些。」這種自信來自克制。

**Gemini 專案的 accessibility 優先**
案例說明：「prioritizing accessibility, performance and best practices」— accessibility 排在 performance 前面。一個產品發布頁如果讓視障使用者無法理解內容，那些精緻的 Lottie 動畫就只是自嗨。

**Yuga Labs 的 generative logo 工具**
不只做了 GLSL shader logo 動畫，還給客戶一個工具讓他們自己調整參數、下載變體用在社群媒體。這是 design system 思維在 motion design 領域的延伸。

**客戶類型的多樣性**
Google、Microsoft、i-D、Yuga Labs、MetaMask — 科技巨頭、時尚媒體、Web3 原生公司。能在完全不同的語境裡保持設計水準，說明方法論是可遷移的。

### Critique
- Hero 影片在慢速連線下會看到黑畫面等待，言行不一
- 案例頁面資訊架構混亂 — 有些完整、有些只有「Coming Soon」，應該隱藏空殼

### Go wild
如果一個 agency 的網站本身就是一個生成系統呢？不是「展示作品」，而是讓訪客用你的設計系統創造東西。首頁是一個 canvas，訪客用你定義的規則組合出自己的畫面。品牌識別不是固定的 logo，而是一套規則。

### Closing
「數位體驗」有沒有意義？有，但前提是你能指著具體的案例說「這是我們做的選擇，這是為什麼」。Antinomy 的網站不只是作品集，是一份論述。
