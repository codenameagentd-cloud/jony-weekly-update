# Design Diary — 2026.5.6

## BLUR (Behance)
- **Source:** Behance — Best of Behance (Interaction Design, May 2026)
- **Project:** https://www.behance.net/gallery/248700095/BLUR
- **Creators:** KyungHoon Choi (Designer) & Seongmin Lee (Creative Director)
- **Tags:** Editorial Design, Fashion Magazine, Typography, Korean Design, Print

### 為什麼選這個
- 在一片 SaaS / dashboard / app UI 中，一本關於「模糊」的時尚雜誌脫穎而出
- 把「邊界不清晰」本身當作設計語言，反其道而行
- 雙語排版（韓/英）的處理方式：承認矛盾、把矛盾變成特色
- 字型不只是資訊載體，是視覺材質

### 設計觀察
- Logo type 直接融入攝影影像，字母筆畫與人物輪廓共享視覺層級
- 人像構圖極度克制：大面積留白逼迫觀者只看姿態、布料、光線
- 內頁韓文被處理成灰色質地色塊，英文 serif 標題與韓文密度形成反差
- 攝影被裁切壓縮，與文字共享視覺權重，不靠佔滿版面證明力量
- 服裝細節（摺線、垂墜、口袋幾何）被當作字型等級的視覺元素構圖

### 延伸思考
- 數位設計是否太執著於清晰？清晰是風格選擇不是絕對真理
- 最好的 brand experience 可能需要故意的模糊——Apple Vision Pro 頁面就有這種品質
- 設計養分從來不在同行裡：只看同類作品 → 不知不覺把別人的解法當唯一解法
