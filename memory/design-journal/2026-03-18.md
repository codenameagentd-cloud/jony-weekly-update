# Design Diary — 2026-03-18

## 2026.3.18 — Opal Camera

**Source:** https://opalcamera.com (Godly featured)
**Notion:** https://www.notion.so/2026-3-18-Opal-Camera-326f6af8fd4d816c8378c4de3203bf78

### 核心觀察
- 硬體公司網站做成設計宣言，克制程度超過大多數設計工作室
- 「攝影敘事」手法：不列規格，用攝影說故事，show don't tell 極致
- 色彩系統：黑白 + Opal Yellow (#FFDB01) 三色系統，功能性用色教科書
- 導覽列用 mix-blend-difference 解決跨色段可讀性問題
- 字型層級極扁平（32px semibold + 14-16px medium）

### 設計技巧提煉
- **展廳 vs 商店**：最好的展廳本身就是商店——退到透明，讓產品做唯一光源
- **功能性單色 accent**：整站黑白灰 + 1 色 = 該色自動獲得不成比例的視覺重量
- **攝影即 UI**：好的產品攝影讓文字說明變多餘
- **mix-blend-difference 實戰**：固定導覽列在黑白區段切換時的優雅方案

### 缺點
- 首頁三欄產品選擇區過於 generic（SaaS pricing page 既視感）
- Footer newsletter 區設計語言斷裂
