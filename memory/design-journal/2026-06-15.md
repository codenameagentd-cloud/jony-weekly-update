# Design Diary — 2026.6.15

## The Bend Club
- **Source:** Awwwards (Nominee, Jun 14 2026)
- **URL:** https://www.thebendclub.com
- **By:** Farewell Creative
- **Tech:** Next.js, GSAP, Tailwind CSS
- **Notion:** https://app.notion.com/p/2026-6-15-The-Bend-Club-37ff6af8fd4d81c8b20ac101191180c9

### 為什麼選這個
一個尚未興建的 16 棟豪宅項目，用攝影和文案（而非渲染圖）賣生活方式。克制到極致的品牌設計。

### 關鍵觀察
1. **Hero 動畫** — Logo 文字拆解（The Bend / Club）夾住膨脹的攝影畫面，品牌認知和空間體驗同步建立
2. **字型選擇** — PP Writer serif，在「奢華」和「人味」之間的精準位置
3. **Logo ligature** — 自訂連筆設計，避開「太企業」和「太手工」兩個陷阱
4. **敘事策略** — 不展示房子，展示「住在這裡的一天」。Mornings/Afternoons/Evenings 三段式
5. **色彩系統** — 只有墨綠 (#17231f)、米白 (#f4f1ea)、champagne 金三色
6. **Contact 表單** — 只有 4 個欄位，刻意省略「預算範圍」，傳達「邀請」而非「篩選」

### 啟發
- 「尚未存在的東西」的設計策略：不用渲染圖填想像，用實景攝影建立生活感
- 信任感不來自展示所有東西，而來自精準地只展示對的東西
- Apple Vision Pro 發表用的是同一個邏輯
