# 2026-07-07 Design Diary

## CHỮ VỊ VIỆT — TYPE COLLECTION
- **Source:** Behance
- **URL:** https://www.behance.net/gallery/250931257/CH-V-VIT-TYPE-COLLECTION
- **Creator:** Phuong Duy (Hanoi, Vietnam)
- **Type:** Typography / Type Design

### Why This One
越南文字型設計——把聲調符號從語言學附屬品提升為獨立視覺主角。觸碰「字型設計能不能同時是文化保存」的核心問題。

### Key Takeaways
1. **聲調符號的空間尊嚴** — 給每個 dấu 獨立呼吸空間，不壓縮在字母上方
2. **分層粗細邏輯** — Thin weight 維持符號存在感，Black weight 控制符號增長速率避免墨團
3. **行距的源頭解法** — 不粗暴加行距，從字型設計壓縮符號垂直佔位
4. **系統性驗證** — 每個字母的所有聲調變體並排展示，位置/角度/粗細有精確邏輯
5. **Inclusive design 從根基重構** — 不是在英文字型裡加 checkbox，是重新思考空間邏輯

### Design Principles Reinforced
- 真正的國際化不只是翻譯，是重新排版整個頁面
- 基礎建設級的設計（字型）能成為文化保存的載體
- 數學般的精確讓最終效果看起來「自然」
