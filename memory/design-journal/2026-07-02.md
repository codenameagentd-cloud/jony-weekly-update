# 2026-07-02 Design Diary

## IVRESS SPIN A TALE
- **Source:** Awwwards SOTD (Jun 28, 2026)
- **URL:** https://brand.ivress.co.jp/
- **Awwwards:** https://www.awwwards.com/sites/ivress-spin-a-tale
- **Studio:** Laugh Mind Co., Ltd. + Utsubo

### Why This One
九章式 scroll storytelling brand site。一間日本企業不賣產品、不推服務，用 WebGL 和文字在黑暗中講了一個關於「旅人與無名者」的故事。在 brand site 都在搶轉換率的 2026 年，這種不要求任何行動的設計立場本身就值得記錄。

### Key Takeaways
1. **極端色彩克制** — 整站只有 #000000 一個色板，所有色彩來自 WebGL 動態光效，光 = 敘事元素而非裝飾
2. **字體間距即書法** — 日文文字每字間刻意全形空格，把「讀」變成「看」，接近杉浦康平式的排版傳統
3. **九章敘事結構** — Prologue → Encounter → Power → Oath → Bond → Trial → Expansion → Spiral → IVRESS，scroll 驅動翻頁
4. **Loading = 敘事開場** — 「ここは、光を拒む世界」不是等待，是氛圍建立
5. **反 CTA 哲學** — 沒有轉換漏斗，整個體驗要求 3 分鐘投入，賭的是「被記住」比「被點擊」重要

### Design Principles Reinforced
- 技術（WebGL）為敘事服務，而非敘事為技術服務
- Brand site 不一定要「有用」，但一定要讓人「有感」
- 最有效的品牌設計可能是完全不像在做品牌設計的那種
