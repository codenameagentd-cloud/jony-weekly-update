# Design Diary — 2026.3.20

## La fresque Ruinart
- **URL:** https://fresque.ruinart.com
- **Source:** Awwwards featured
- **By:** Manon Diemer (illustrator) for Ruinart (est. 1729, first champagne house)
- **Concept:** Interactive illustrated fresco — horizontal scrolling narrative through 300 years of champagne history
- **Key insights:**
  - Illustration as brand differentiation: hand-drawn warmth vs photographic coldness
  - Horizontal scroll as "walking through" a painting — metaphor made interaction
  - Interactive objects without explicit UI cues — trusting user curiosity
  - Parchment/cream color palette carrying historical weight without heaviness
- **Criticism:** Heavy first load (5000px panorama + 25+ items), mobile horizontal scroll fights muscle memory, low completion rate risk
- **Go wild:** Living fresco that grows yearly, visitor-participatory elements
- **Notion:** https://www.notion.so/2026-3-20-La-fresque-Ruinart-328f6af8fd4d811dacb1c720cebd3f3c
