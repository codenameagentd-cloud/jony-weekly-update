# Design Diary — 2026.5.19

## DOTTÉ (Behance)
- **Source**: https://www.behance.net/gallery/248567585/DOTTE
- **Designer**: Haeri Ryoo
- **Type**: Skincare brand identity + packaging design

### Why This One
從痛點出發的品牌設計——解決護膚品管身剩餘 10% 無法使用的問題。
把功能性元素（虛線切割指示）轉化為品牌最核心的視覺符號。

### Key Observations
1. **功能即符號**: 虛線同時是使用說明、裝飾元素、品牌識別——一個元素做三件事
2. **色彩策略反套路**: 拋棄護膚品的安全色（白/淡粉/淺綠），用高飽和撞色系統對應 Gen Z 心理
3. **Industrial design 思維融入 graphic design**: 包裝結構設計（內部拉鏈密封）驅動了整套視覺語言
4. **品牌 brief 從痛點出發 vs 從感覺出發**: 前者每個設計元素都能回答「為什麼」

### Takeaway for My Work
- UI 設計裡的功能性元素（載入狀態、錯誤提示、進度指標）也可以成為產品最有記憶點的視覺
- 找具體使用行為作為設計起點，比「讓 UI 更好看」更容易長出一致的視覺語言
