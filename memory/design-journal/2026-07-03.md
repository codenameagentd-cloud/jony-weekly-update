# 2026-07-03 Design Diary

## The Bend Club
- **Source:** Awwwards Nominee
- **URL:** https://www.thebendclub.com
- **Awwwards:** https://www.awwwards.com/sites/the-bend-club
- **Tech:** Next.js

### Why This One
一個還不存在的豪華住宅俱樂部投資人網站。在所有高端地產站都在堆航拍和 3D 漫遊的 2026，它選了完全相反的路：最少視覺元素，最大慾望。

### Key Takeaways
1. **模糊 > 清晰** — 產品不存在時，模糊攝影比渲染圖更有說服力。清晰 = 承諾，模糊 = 想像空間
2. **Logo 拆分張力** — "The Bend" 和 "Club" 拆成兩個 SVG，距離感即品牌個性
3. **CTA 缺席策略** — 整站沒有視線中央的 CTA 按鈕，行動呼籲推到邊緣/底部。「如果需要被催促才行動，你不是目標客戶」
4. **留白即定價** — 首屏除 logo 和 tagline 什麼都沒有，在奢侈品設計裡，空白 = 價值信號
5. **Emotion > Information** — 攝影不展示「長什麼樣」，而是傳達「在這裡的感覺」

### Design Principles Reinforced
- 最難的設計決策是決定不做什麼
- 技術能力隱藏在表面的靜謐之下（Next.js 有能力做複雜互動但選擇不做）
- 在所有人都在喊的房間裡，低語才是真正的奢侈
