## Key Takeaways
- Iowan Old Style serif self-hosted (3 weights only) — intentional restraint
- 5 color variables total: white, #474747, #999, two yellows (selection only)
- CSS @layer architecture: configuration + main — clean separation
- `rlh` (root line height) as spacing unit — all spacing breathes with text
- clamp() for fluid type: 14px–26px font, 26px–48px line-height — zero breakpoints for type
- Archive hover: single `transition-property: gap` — minimal but effective interaction
- text-column: 20rlh — proportions derived from typography, not arbitrary grid

## Design Principle Extracted
當間距從文字節奏派生（rlh）而非抽象 grid（8pt），介面更像書頁而非 spreadsheet。
