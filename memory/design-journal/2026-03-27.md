# 2026-03-27 Design Diary — Will Phan

**Source:** minimal.gallery → willphan.com
**Notion:** https://www.notion.so/2026-3-27-Will-Phan-32ff6af8fd4d816da656f89aecddcc4e

## Key Takeaways

- **Design Engineer ≠ designer who codes.** Will Phan 用 CSS 的底層機制（backdrop-filter + mask-image radial-gradient）做出相機景深效果，這種對原理的掌握才是真正的 design engineering
- **作品集結構：Clients + Components 二元結構** — 同時展示商業交付能力和技術思考深度
- **克制即自信** — 沒有 hero section、沒有大標題宣言，作品直接說話
- **Orb 概念的空間思維** — UI 設計不是畫介面，是設計使用者身處的空間
- **影片 > 截圖** — 案例用全幅影片呈現產品活著的樣子，而不是功能截圖

## Reflection

在 AI 能寫大部分 CSS 的時代，design engineer 的價值在於「用 CSS 說一個別人說不出的故事」。互動設計的核心不是元件，是感覺。
