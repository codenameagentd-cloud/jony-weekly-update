# 2026-03-28 Design Diary — Tayte.co

**Source:** minimal.gallery (March 2026 feature)
**Site:** https://www.tayte.co
**Studio:** Tayte Stubbersfield, Australia
**Notion:** https://www.notion.so/2026-3-28-Tayte-co-330f6af8fd4d81cfb447e11b1225f0ba

## Key Observations
- "Minimal intervention design & development" — not minimal design, but minimal *intervention*
- 11px base font size (0.6875rem) — radical restraint in 2026
- Montreal Medium typeface, 3-color palette (#FFF, #1A1A19, #ABABA8) + one functional blue (#007AFF)
- 12-col grid, 0.0625rem column gap — nearly invisible structure
- All projects shown as Mux video streams, no static screenshots
- Project cards: opacity:0 + blur(2px) → fade in at 800ms with custom cubic-bezier
- Footer: pure CSS clock with blue second hand — only dynamic element on a static page
- Transition timing system: 100ms/150ms/200ms/500ms/800ms — a complete temporal language

## Design Takeaway
The most powerful choice is sometimes to step back. Trust content to speak for itself. "Minimal intervention" is an attitude, not just an aesthetic — ask "does this really need me?" before every design decision.
