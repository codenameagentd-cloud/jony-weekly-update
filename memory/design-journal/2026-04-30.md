# Design Diary — 2026.4.30

## Lost Memories (minimal.gallery)
- **Source:** minimal.gallery
- **Site:** https://lostmemories.space
- **Creator:** Guilherme Lucas
- **Tech:** Next.js + Sanity CMS + Tailwind CSS
- **minimal.gallery:** https://minimal.gallery/lost-memories/

### 為什麼選這個
- 攝影收藏網站，照片來自北京潘家園舊貨市場的陌生人老照片
- 極端克制的介面設計：UI 幾乎不存在，內容就是設計
- SVG noise texture overlay 創造紙張觸感
- 照片以真實掃描比例呈現，不是等寬網格

### 設計觀察
- 字體組合：Gaegu（手寫）+ IBM Plex Mono — 溫暖與冰冷的矛盾
- 導航 mix-blend-difference，只有 home / title / about 三個元素
- Hover 時其餘照片 opacity 降低 — 模擬注意力聚焦
- 10px mono 控制面板：scale slider、type filter、location filter
- SVG feTurbulence noise overlay（opacity 0.2）統一視覺溫度
- 404 頁："The memory you're trying to find is lost forever"

### 核心洞察
- 最好的介面不是隱形的，是知道什麼時候該閉嘴的
- 用真實尺度還原物理實體 > 用設計系統規範化
- SVG noise + pure white = 紙張觸感，零裝飾代碼
- 照片從鞋盒裡倒出來的那一刻，設計就已經完成了
