# 2026-06-28 Design Diary — SITCON 2026: Jam the Chaos

**Source:** Awwwards Nominee (June 27, 2026)
**URL:** https://sitcon.org/2026/
**Designer:** Elvis Mao
**Tech:** Next.js / Three.js (scroll-reactive vortex, 3D venue map)

## Why This One

台灣學生自主辦的科技研討會，沒有商業預算卻做出 Awwwards nominee 水準。主題「Jam the Chaos」被完整翻譯成視覺系統——從首頁漩渦到議程表的有序 grid，整個網站是概念→視覺的敘事鏈。

## Key Takeaways

1. **Scroll-reactive > Mouse-reactive** — 漩渦用 scroll 而非 mouse move 觸發，有方向感和節奏
2. **講者區段的 hover 互動** — 靜態克制（只有名字），hover 時照片浮現改變整個區域視覺重心
3. **3D 會場地圖解決真實需求** — 多樓層平行議程需要空間導引，3D 不是炫技
4. **議程表的資訊設計硬功夫** — 色彩編碼、時間軸縱向、方塊高度=時長、responsive 重新設計而非橫向捲動
5. **暗色調+高對比文字+大量留白** — 沒有漸層沒有色塊分界，只有文字和空間張力

## Design Principle Extracted

「概念到視覺的翻譯鏈」— 每個技術選擇必須直接回應一個設計問題。不是因為學了所以想用，而是因為問題需要這個解法。
