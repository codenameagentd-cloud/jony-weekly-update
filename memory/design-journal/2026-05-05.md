# Design Diary — 2026.5.5

## Kindred of Ireland (Awwwards SOTD)
- **Source:** Awwwards SOTD
- **Site:** https://kindredofireland.com
- **Studio:** Dash (Ireland)
- **Platform:** Shopify
- **Tags:** E-Commerce, Fashion, Typography, Video, Storytelling

### 為什麼選這個
- 在一片科技產品和 SaaS 中，一個 Shopify 電商做到 Awwwards SOTD
- 極度克制的色彩策略：色板從材料（愛爾蘭亞麻）提取，連「1 功能色」都不需要
- Serif 字型擁抱傳統而非用 sans-serif 現代化——字體選擇本身就是品牌宣言
- 證明工具不決定上限：Shopify 框架下的設計品質

### 設計觀察
- Hero：影片當材質而非裝飾，大寫 serif 壓在影片上方，字母骨架與布料經緯呼應
- 色彩：未漂白亞麻米白、天然染色深灰、愛爾蘭天空灰藍——全從物理現實提取
- 產品頁：每件衣服有獨立「舞台」，大面積留白強迫使用者慢下來
- 404 頁：unusual grid layout，打破常規讓「迷路」成為品牌敘事延伸
- 動效克制：不做 parallax，布料垂墜感就是最好的動態

### 延伸想法
- 「不做」的決定比「做」更難，需要設計信念 + 客戶信任
- 技術複雜度 ≠ 設計價值，care 比 shader 重要
- 跟昨天 Fetco 壁畫的共通點：好色彩從產品物理現實長出來
