# Design Diary — 2026.5.22

## Obys Agency (minimal.gallery)
- **Source**: https://obys.agency
- **Found via**: minimal.gallery (May 2026)
- **Creator**: Obys Agency — EU-based concept-driven design studio
- **Type**: Studio portfolio / Design system showcase
- **Tags**: Minimal, WebGL, Typography, Next.js, Custom Font, Layout Modes

### Why This One
不是因為動畫厲害（雖然 WebGL canvas 技術很深），而是因為它解決了一個作品集設計的根本問題：如何讓「系統」本身成為品牌。自定義字體 Obys Sans 就是品牌，三種 layout 模式就是設計哲學，side projects 就是立場聲明。

### Key Observations
1. **自定義字體 = 品牌**：一個 woff2 文件，font-display: swap，無第三方依賴。字體就是 brand guidelines
2. **三種 Layout 模式**：Vertical（編輯式）、Horizontal（展覽式）、Grid（目錄式）— 不是功能堆疊，是對「觀看方式」的尊重
3. **嚴格的比例控制**：1:1、4:5、3:2 不同比例像音樂的拍號轉換，創造視覺重量變化
4. **WebGL + DOM 解耦**：全局 #gl canvas 處理所有視覺渲染，DOM 只負責內容和互動。用最複雜的技術實現最克制的視覺
5. **Side Projects 即立場**：Grids、Design Education Series、Abetka — 設計教育本身就是好設計

### Extended Thinking
- 最好的作品集不是展示你做過什麼，而是展示你怎麼思考
- 品牌一致性的終極形態：任何頁面截圖抽掉 header 依然能認出
- 「做中教、教中做」讓作品集從銷售工具變成立場聲明
