# Design Diary — 2026.4.29

## Silent House (Awwwards SOTD)
- **Site:** https://silent-house.com/
- **Studio:** Milkshake Studio
- **Tech:** Svelte + Tailwind CSS
- **Awwwards:** https://www.awwwards.com/sites/silent-house

### 為什麼選這個
- 娛樂產業（演唱會製作公司）卻用極簡設計，反直覺的品牌策略
- 用安靜呈現喧囂，用留白暗示能量

### 設計觀察
- Hero 全幅暗調攝影，無 CTA、無 showreel 自動播放
- 專案頁攝影主導敘事，UI 幾乎隱形
- 過場動畫：透視旋轉掀頁效果 ~1.2s，功能性而非裝飾性
- Svelte 選型 = 性能優先策略，有 runtime 餘裕做影片和動畫

### 核心洞察
- 能忍住不設計的設計師 > 什麼都想設計的設計師
- 在所有人都在尖叫的房間裡，低語的人最引人注目
- 技術選型是設計決策的一部分
