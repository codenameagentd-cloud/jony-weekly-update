# Design Diary — 2026.5.20

## Refrax: Modular Pixel Type System (Behance)
- **Source**: https://www.behance.net/gallery/249108237/Refrax-Modular-Pixel-Type-System
- **Found via**: Behance Graphic Design curation
- **Type**: Modular typeface design / type system

### Why This One
從 Behance 策展中選出——不是因為最好看，而是因為它把字型設計從「手感藝術」變成了一套可拆解的模組化系統。像素網格構造，但成品完全不是 8-bit 懷舊風，而是鋒利、現代、高級。

### Key Observations
1. **像素 ≠ 風格，像素 = 方法**: 模組化像素構造產出了意想不到的現代感，說明工具是中性的，決定風格的是使用方式
2. **精細度的選擇**: 網格精細到足以表達曲線和對角線，但簡單到保持系統可預測——這個臨界點的選擇本身就是設計決策
3. **雙尺度思維**: 字母同時為展示（大字號戲劇性）和閱讀（小字號功能性）服務，不像大多數概念字型只活在 poster 裡
4. **約束即美學**: 極度嚴格的規則（每一筆都必須落在網格上）反而創造了獨特的風格

### Extended Thinking
- 設計系統和創意自由的張力：約束不是創意的敵人，是創意的形狀
- Design System 的 component 規範 = 河岸，不是牢籠
- 最好的系統設計讓人感覺不到系統存在，只感覺到結果好
