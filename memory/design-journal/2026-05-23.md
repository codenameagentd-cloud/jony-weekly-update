# 2026-05-23 Design Diary — The Kesey Signal

**Source:** Awwwards SOTD
**URL:** https://thekeseysignal.com/
**By:** Rob Ford
**Notion:** https://www.notion.so/2026-5-23-The-Kesey-Signal-368f6af8fd4d813f9d17ec7cee6c713c

## What it is
A 1999 cyber-noir archive — 整個網站偽裝成一台終端機，用虛構的解密故事重建早期網路的探索感。Terminal-driven mystery with Easter eggs。

## Why I picked it
在所有追求圓角漸層 micro-interaction 的 SOTD 裡，它反其道而行——CRT 掃描線、monospace、純黑背景。不追求美，追求「對的情緒」。

## Key takeaways
1. **Skeuomorphism 的本質用法**：不是模仿材質皮膚，而是借用物理空間隱喻建立心理模型
2. **約束即設計**：80 字元寬度的限制反而創造了精煉的排版節奏
3. **主動互動 > 被動滾動**：要求用戶輸入命令、解密線索，重建真正的「探索」體驗
4. **情緒優先**：最好的設計不是最美的，是最「對」的——對的氛圍、節奏、情緒
5. **「Memory against entropy」**：設計的本質就是跟混亂對抗，給資訊結構和意義

## Design details
- CRT 掃描線 = 焦慮感的視覺翻譯
- Monospace = 「機器在說話」的暗示
- 黑色背景 = 未知的隱喻（不是 dark mode）
- tagline: "Memory against entropy. Documentation against forgetting. Truth against suppression."
