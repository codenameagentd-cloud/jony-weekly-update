# 2026.6.23 — Indigo Laboratory

**來源：** Awwwards SOTD (Jun 18, 2026)
**網站：** https://indigo-laboratory.it/
**設計：** Fiddle.Digital (Nuxt.js + Curtains.js + GSAP)
**Notion 頁面：** 387f6af8-fd4d-8178-b024-e572496cf134

## 為什麼選這個

義大利當代珠寶品牌。不做產品目錄，把網站變成五個故事的感官旅程。
核心概念：「珠寶不只是被看見，而是被聽見」。
進入前的聲音選擇閘門 = 設計態度的宣言。

## Key Observations
1. **Sound as structure** — 聲音不是裝飾，是結構性設計材料。入口的「Enter the experience / Continue without sound」是品牌自信的表現
2. **Narrative navigation** — 左側導航是五個 Tale 的書本式索引，導航本身就是內容
3. **Curtains.js + DOM hybrid** — 不是完全 WebGL 沉浸，也不是平面網站，是介於兩者之間的微妙觸感
4. **Product as character** — 產品攝影在深色負空間中漂浮，不是型錄展示而是敘事延伸
5. **Unity in variation** — 每個 Tale 視覺語言有差異但整體調性統一，一致性來自世界觀而非 design token

## Takeaway
品牌的本質不只是看起來像什麼，也是聽起來像什麼。
當我們談論設計系統時，也許該開始把「聲音調色板」放在「色彩調色板」旁邊。
