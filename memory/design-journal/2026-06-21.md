## 為什麼選這個

義大利設計機構 20 週年品牌重塑。不展示任何案例細節，只反覆傳達一句話：「我們設計溝通的生態系統」。技術務實（React + Tailwind v4.2），設計激進。

## 設計重點

- **極端字級比（50:1）**：Bebas Neue 巨型標題 vs 9px uppercase label，只有兩個字級，沒有中間地帶
- **三色系統**：純黑 #000 + 純白 #fff + 紅 #ff3333。紅只出現在 active/hover/CTA
- **自製游標系統**：全局 cursor:none，自製圓形光標 + cubic-bezier(.2,.9,.2,1) 物理慣性曲線
- **Tetris Footer**：footer 做成積木式互動佈局，打破功能性區塊的刻板印象
- **字型選擇**：Bebas Neue（condensed display）+ News Cycle（humanist body），只有兩套
- **技術棧**：React + Tailwind CSS v4.2，無 WebGL/Three.js/GSAP，純 CSS 動畫
- **prefers-reduced-motion**：完整支援無動畫 fallback

## 延伸思考

「務實的技術 + 激進的設計」組合比「激進的技術 + 平庸的設計」難做得多。創意不依賴工具——不是因為用了 WebGL 才厲害，是因為排版、節奏、色彩的決定本身就厲害。品牌是決定的總和。
