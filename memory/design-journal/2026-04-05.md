# Design Diary — 2026-04-05

## Manu Moreale (manuelmoreale.com)
- **Source:** minimal.gallery
- **Why:** 極致克制的個人部落格，用 Iowan Old Style + rlh 單位建立完整的排版系統
- **Key takeaways:**
  - 字體選擇：Iowan Old Style（John Downer 為 Apple iBooks 設計的螢幕襯線體）
  - rlh（root line height）單位：所有間距基於行高倍數，排版空間與文字呼吸同步
  - Fluid typography：clamp(14px, 0.45vi + 12.42px, 26px)，450px-3500px 全覆蓋
  - 色彩：#474747 暖灰文字 + #f9f9f9 微暖背景 + 雙黃（#FFF7B1 selection / #FFEE50 備用）
  - Archive list：dotted border-top 引導線 opacity:0.2 + hover gap 動畫 0.25→0.5rlh
  - Responsive：幾乎無 media query，fluid 設計讓佈局自然適應
  - CSS 架構：@layer 管理、手寫 CSS、無 build step、< 300 行
  - 唯一的 breakpoint：420px 以下 archive 標籤用 data-compact attr() 切換
- **Core insight:** 最好的介面設計是讓你忘記介面存在——rlh 單位值得在專案中實驗
