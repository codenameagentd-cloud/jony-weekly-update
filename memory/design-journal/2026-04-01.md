# 2026-04-01 Design Diary — Kometa Typefaces

**Source:** minimal.gallery → kometatype.com
**Notion:** https://www.notion.so/2026-4-1-Kometa-Typefaces-334f6af8fd4d8155b215c113d5982298

## Key Takeaways

1. **「AI couldn't invent」作為品牌定位** — 在 AI 字體生成越來越成熟的 2026，Kometa 選擇把「人的執著」當核心價值。不是技術差異，是 care 的差異
2. **展示即論證** — 首屏全黑，只有字體本身。不解釋品質，直接展示。自信的設計決策
3. **選詞的功力** — 用 Burial、Craftsman、Antiquitatis 等詞展示字形，每個詞都在測試字體的不同特質。比 pangram 高明得多
4. **Live type tester 的預設值** — 80px Bold 作為預設，直接給用戶看最有表現力的狀態。「替用戶做決定」的哲學
5. **整站只有黑白** — 零裝飾、零色彩，讓字體成為唯一的視覺元素

## Design Pattern Worth Stealing
- 賣的是什麼，頁面就只有什麼。不加任何多餘元素。終極的 material honesty
