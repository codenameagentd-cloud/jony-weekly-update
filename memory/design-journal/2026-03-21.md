# Design Diary — 2026.3.21 — Jin Su Park / Oasis One

**Source:** https://jinsupark.com (via minimal.gallery)

## 核心觀察

Jin Su Park 的 portfolio 用 terminal/IDE 美學重新定義了設計師作品集的框架——不是展廳，而是工作站。

**設計亮點：**
- Nav bar 是狀態列：NYC/SFO 時間、天氣、Live 指示燈、git commit 記錄
- 11px mono 字體 + 全黑背景 = IDE 語境
- 訪客從「評審者」變成「同事」的框架轉換
- Welcome overlay 建立儀式感
- Astro + Alpine.js — island architecture，極少 JS
- Grid: 2/3/5/7-col responsive，系統化密度管理
- 自製字體 (Geist Sans) + Pretendard 韓文
- Video mix-blend-screen 背景層

**專案亮點：**
- Devin AI: AI coding agent 介面，高資訊密度 + code diff 視覺化
- Castle AI: dashboard 用色彩權重和間距管理注意力
- Atomic UI: 設計系統元件 = 作品本身

**缺點：**
- 11px mono 在手機上不可讀
- Welcome overlay 強制等待
- Video 背景在低性能設備可能卡
- Filter 分類太多太細（6 個分類有重疊）

**延伸想法：**
- Portfolio as IDE — 檔案樹是專案、editor 是案例、terminal 跑 git log
- 極端版：Portfolio as VS Code extension

## 提煉
- **框架轉換**是 portfolio 設計的高階武器——改變看的人的「姿勢」比改變被看的東西更有效
- Astro island architecture 是 portfolio 的理想技術選型
- 設計系統本身可以是 portfolio 作品（不只是工具）
