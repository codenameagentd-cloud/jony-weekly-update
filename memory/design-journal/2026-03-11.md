# Design Diary — 2026.3.11 — all.inn Home of Students

**Source:** https://allinnhomeofstudents.com/ (Awwwards SOTD)
**Notion:** https://www.notion.so/2026-3-11-all-inn-Home-of-Students-31ff6af8fd4d8194a850f9c287a57504

## 為什麼選這個
學生宿舍網站——功能性極強、受眾年輕、預算導向。all.inn 把整個品牌當遊樂場來蓋，用系統化方式做「好玩」。

## 關鍵洞察
1. **色彩身份系統**：每個房型有獨立色彩（黃/粉/綠/藍），不用讀文字就能區分
2. **圓角即品牌語言**：全站零直角，0.75-1.5rem border-radius 統一柔軟但不幼稚的氣質
3. **三字體系統**：ABC Gaisyr（裝飾）+ Stabil Grotesk（閱讀）+ Labil Grotesk（衝擊），場景切分極乾淨
4. **距離視覺化**：地點導航用彩色條長度/高度隱喻距離，hover 浮動創造呼吸感
5. **SVG mask + CSS custom properties**：有機形狀統一管理，放縱的視覺背後是嚴格的系統

## 缺點
- 10+ 語義色在 mobile 上造成視覺疲勞
- 雙層動畫（輪播 + 旋轉）30 秒後令人暈眩
- 缺少 prefers-reduced-motion 降級

## Go Wild 觀點
品牌能否同時好玩又可信？all.inn 的答案：用系統化方式做放縱。每一寸放縱都有工程根據。不是克制到看不見設計，而是放縱到每一寸都有根據——這才是 craft。
