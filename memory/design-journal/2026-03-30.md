# 2026-03-30 Design Diary — Karl.Works

**作品：** [Karl.Works](https://karl.works) — UK freelance designer portfolio on Cargo
**Notion：** https://www.notion.so/2026-3-30-Karl-Works-332f6af8fd4d811f8d37e28ae50e087e

## 核心觀察
- 整站套 CSS color filter（grayscale + red lighten blend）→ 統一紅黑雙色調
- 只有一頁，沒有作品展示，底部寫 "Request full case studies"
- ROM Condensed Variable 大標題 letter-spacing: -0.05em, line-height: 0.9
- 品牌列表用 marquee 滾動 + 降低對比度 → 氛圍而非清單
- Nav 用 mix-blend-mode: difference
- "in sunny London" 用刪除線 → 搬家事實變成人格細節

## 設計啟發
- 一個強烈到不可能被忽略的視覺決定 > 十個平庸的頁面
- 克制 = 信心的表現
- Color filter 是一種低成本高回報的品牌策略
