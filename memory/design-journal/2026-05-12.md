# Design Diary — 2026.5.12

## timespent | Habit Tracker Landing Page (Minimal Gallery)
- **Source:** minimal.gallery
- **Project:** https://timespent.so
- **Creator:** @hicalkim (indie dev)
- **Stack:** Static HTML + Bricolage Grotesque + 11ty image pipeline (avif/webp/jpeg)
- **Typography:** Bricolage Grotesque (headlines) + SF Mono (mono accents)
- **Color System:** 12 equalized brand colors (same saturation/brightness range)
- **Notion Page:** https://www.notion.so/2026-5-12-timespent-35df6af8fd4d81dea2c3c86f0bd1a12c

### 為什麼選這個
- 獨立開發者做的 habit tracker，landing page 卻有 Apple 產品頁等級的克制
- Hero 只有三個詞「Focus. Flourish. Go timespent.」——文案克制到極致
- Widget wall 用無限橫滾展示數十種 widget，每張都是真實 app 截圖而非 mockup
- 12 種品牌色的飽和度/亮度統一，建立「怎麼選都不會錯」的色彩系統
- 不賣功能賣畫面——讓你看見產品存在於你生活裡的感覺

### 設計觀察
- **Bricolage Grotesque 選型：** 手工感 grotesque，比 Inter 暖、比 Playfair 克制
- **Widget 色彩語言：** 每個 activity 一個色（綠=walking、藍=focus、紅=deadlift），不混色不漸層
- **信息建築：** focus trend widget 三層資訊（進度環→折線→數字），按視覺重量排序閱讀順序
- **Dark/Light 雙模式：** 每張 widget 圖都有 light-only/dark-only 版本，CSS class 切換
- **App Store Editors' Choice badge** 放在 hero 而不是獨立 section，融入而非強調

### 可借鏡
- 色彩系統設計：不是選「最好看的一組」，而是建立「怎麼選都不會錯的一組」
- 產品展示策略：不列 feature，讓產品畫面自己說話
- Widget 作為設計語言：用 widget 截圖代替傳統的 feature screenshot
