# Design Diary — 2026.4.3

## Tayte.co
- **Source:** minimal.gallery → https://www.tayte.co
- **Notion:** https://www.notion.so/2026-4-3-Tayte-co-336f6af8fd4d812a9984dedf264265c5
- **主題：** Minimal intervention design — 用釀酒哲學做設計
- **關鍵觀察：**
  1. 時鐘作為 hero：三根指針分別指向 IG、email、定位語，沒有傳統 hero image
  2. Notch 造型 SVG：每張作品卡片頂部有 MacBook 缺口隱喻，作品被「播放」不是「展示」
  3. Mux 影片取代靜態截圖：技術決策 = 設計決策
  4. 一致的容器格式（notch + 全幅影片 + 一行標題）：重複是紀律不是偷懶
  5. 「Minimal intervention」= 自然酒哲學：最好的設計是最少的設計
- **延伸思考：** 我們行業裡有多少設計在解決設計師自己製造的問題？
