# 2026-04-11 Design Diary — Linear

**作品：** [Linear](https://linear.app)
**來源：** siiimple gallery 瀏覽
**Notion 頁面：** https://www.notion.so/2026-4-11-Linear-33ff6af8fd4d8114aa06f4737ccb47d5

## 重點觀察

1. **Tagline 轉向系統定位**：「The system for product development」+ AI agents 副標，從工具→系統的哲學宣言
2. **產品截圖即行銷**：Hero 區直接放真實 UI 截圖，不用概念插畫，展現對產品設計的極度自信
3. **克制的社會證明**：客戶 logo 灰階處理，推薦語錄純文字，不消費客戶品牌光環
4. **功能展示用真實 UI**：每個功能直接展示對應 UI 片段，尊重使用者智力
5. **字體層級極簡**：三個字級 + 黑白灰 + 品牌紫

## 延伸思考

- AI 時代的 UI 語言不需要改變——好的介面對人和 AI agent 都友善
- System vs Tool vs Platform 的定位差異：系統是你身處其中的，工具是你拿起來用的
