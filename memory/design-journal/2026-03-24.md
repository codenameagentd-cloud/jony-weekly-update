# Design Diary — 2026.3.24

## Vlad Savruk
- **Source:** minimal.gallery
- **URL:** https://vladsavruk.com
- **Category:** Designer portfolio / archive
- **Why picked:** Extreme restraint in a personal portfolio — no tricks, no inflated titles, just "I design and build things." The confidence to let work speak.

### Key observations
1. **Serif + sans-serif mixed typography** — name in serif for weight, description in sans for clarity. Intentional type pairing signals respect for tradition + modernity.
2. **Coverflow interaction for projects** — portfolio browsing as tactile experience, not scroll-and-forget. Each project shows 4 curated images.
3. **"Craft, software, intention"** — three words, zero filler. Anti-LinkedIn copywriting that communicates values through omission.
4. **Style range with consistent quality** — Castle (warm/luxe) vs Comp AI (cool/restrained) vs Answer One (humanist/warm). Different personalities, same quality bar.
5. **AI branding without AI clichés** — Comp AI uses dark backgrounds and clean UI instead of rainbow gradients. Restraint in 2026's AI visual landscape.

### Design takeaway
The best portfolio doesn't show what you can do — it shows what you care about. Vlad's site *is* the work: the restraint in the copy mirrors the restraint in the design. When your container and content share the same values, that's integrity.
