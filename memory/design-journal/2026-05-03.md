# Design Diary — 2026.5.3

## Lost Memories (Minimal Gallery)
- **Source:** Minimal Gallery (recently featured)
- **Site:** https://www.lostmemories.space/
- **Concept:** A collection of found photos and film from travels around the world
- **Tech:** Next.js + Sanity CMS + View Transition API
- **Typography:** IBM Plex Mono (全站大寫) + Gaegu (韓國手寫字體, 標題)
- **Featured on:** https://minimal.gallery/lost-memories/

### 為什麼選這個
- 不是在展示設計，而是在展示一種態度——保存被遺失的記憶
- 照片以原始比例排列在白底上（非 grid/masonry），像在桌上攤開實物
- 只有編號、沒有標題、沒有故事——忠實呈現「不可知」
- 404 頁面寫著「The memory you're trying to find is lost forever」——第一次被 404 打動

### 設計觀察
- 佈局：照片按原始比例呈現，底部對齊、頂部參差，scale slider 全域控制
- 互動：照片可翻轉看背面（手寫字、沖印標記），View Transition 做列表↔詳情切換
- 視覺處理：SVG noise texture (opacity 0.2) 覆蓋，模擬老相紙顆粒感
- 導航：mix-blend-difference + grayscale，文字融入照片而非遮罩
- 每張照片下方只有像素尺寸 + 三位數編號（10px mono 字體）

### 核心洞察
- 介面的職責不只是「呈現」，有時是「承載」——讓內容以自己的形狀存在
- 不整齊、不完美、不可解釋的內容，不應該被強行塞進統一的 card component
- 「不知道」是合法的信息狀態——好的設計能容納「空白」和「殘缺」
- 安靜 > 喊叫。最好的作品讓你自己靠近，而不是跳出來吸引你
