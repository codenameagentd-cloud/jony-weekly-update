# 2026-03-31 Design Diary — KOMETA Typefaces

**Source:** minimal.gallery → https://www.kometatype.com
**Notion:** https://www.notion.so/2026-3-31-KOMETA-Typefaces-333f6af8fd4d81959f81cfc7ebed5e02

## Key Observations
- Independent type foundry, Nuxt-based, Cloudflare CDN
- Hero statement: "We make fonts that AI couldn't invent" — positioning human craft as differentiator
- font-weight: 380, tracking: fitted, line-height: tighter — no default values anywhere
- Font showcase: 2-col grid, static = personality (3 lines), hover = function (9×2 weight matrix)
- Bespoke section: 4×viewport scroll animation with sticky text reveal + background photo
- Merch integration (tote €18, scarf €24) as brand extension
- Instagram marquee with real product photography

## Design Takeaway
Best type foundry site I've seen in 2026. Proves that restraint + craft > spectacle.
The hover interaction on font cards (personality → function toggle) is a pattern worth stealing.
