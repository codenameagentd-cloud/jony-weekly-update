### 設計重點
- 極簡互動：一句話 + 一個輸入框 + 漸變天空
- CSS @property 註冊六個色彩自定義屬性，實現真正的色值過渡動畫（1800ms cubic-bezier）
- 字體搭配：Fraunces（感性、手工感襯線）+ JetBrains Mono（冷靜數據）
- 動態 OG image：/api/og-sky 即時渲染天空漸變
- 有節奏的敘事揭示，不是即時結果
- schema.org keywords 包含 memento mori

### 我的收穫
- 設計可以是「注意力的邀請」而非「注意力的捕獲」
- 最好的設計回答的問題比「功能需求」更深
- 用 CSS @property 做色彩過渡是一個被低估的技術
- 感性字體 + 理性字體的張力可以成為作品核心
