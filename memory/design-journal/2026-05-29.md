# Design Diary — 2026.5.29

## Blit Studio
- **Source:** Awwwards Nominee
- **URL:** https://blit.studio/
- **Notion:** https://www.notion.so/2026-5-29-Blit-Studio-36ef6af8fd4d819287a0c996ccbe3db7

### Why This
Immersive experiences studio 把自己的網站做成了一件作品本身，不只是作品集容器。暗場美學、3D WebGL 雕塑 hero、詩意碎片式文案。WordPress + WebGL + GSAP 的務實技術組合。

### Key Observations
1. **暗場即舞台** — 黑色背景不是裝飾，是還原他們作品存在的環境（實體沉浸式裝置）
2. **無文案 hero** — 首屏只放 3D 雕塑，零 tagline，信任視覺自己說話
3. **美術館式案例展示** — 影片/大圖佔滿視野，文字只在邊角出現，像牆面說明牌
4. **情緒錨點** — 散落的詩意短語（「poetics of interference」）不解釋，只停頓
5. **技術為表達服務** — WordPress CMS + WebGL + GSAP，不追 framework 時髦

### Design Takeaway
作品集網站的本質不是「展示作品」，而是「證明你理解自己在做什麼」。讓網站本身成為一次沉浸式體驗，是最高級的說服。
