# Design Diary — 2026.6.2

## Obys Agency
- **Source:** minimal.gallery
- **URL:** https://obys.agency
- **By:** Obys Agency (Concept-driven design studio, EU-based)
- **Key Insight:** 在所有 design agency 都在比誰更吵的品類裡，Obys 選擇安靜——自定義字體 Obys Sans、極低信息密度、case study 入口只放一張精心構圖的照片而非十張流程圖。能力的最高級展示不是堆疊，是結果好到不需要解釋。
- **Design Lesson:** 自定義字體是品牌聲音的物質載體（用 Inter = 跟所有人一樣「專業」的邏輯矛盾）；project grid 的大—小—大節奏像攝影集而非作品清單；About 頁用紀錄片攝影語言取代大頭照 grid
- **Technique:** Custom typeface (Obys Sans), Next.js + encrypted seed, project grid with editorial rhythm, unified documentary photography for team/studio
