# Design Diary — 2026-05-27

## EY Doberman (doberman.co)
- **Source:** minimal.gallery
- **URL:** https://doberman.co
- **Notion:** https://www.notion.so/2026-5-27-EY-Doberman-36cf6af8fd4d81269093e4df9eb4fe7f

### Why This
北歐設計傳奇，25 年歷史，服務過 MoMA、IBM、IKEA、H&M。官網本身就是最好的案例——在所有 agency 都在比 WebGL 的時代，Doberman 選擇讓作品說話、讓介面消失。

### Key Insights
1. **Kassa（挪威房貸）**：三個方塊 = 整個品牌語言。「盒子」的隱喻直接變成視覺系統。Rams 式的少即是多。
2. **MoMA 數位系統**：「品牌音量旋鈕」概念 — 購票流程品牌退後、展覽頁面品牌全開。Responsive branding > responsive design。
3. **Mojo（男性生育力檢測）**：用設計消除恥感。包裝無 logo、送貨無品牌名、粉色調性打破醫療冰冷感。以使用者最脆弱的時刻為設計起點。

### Design Takeaway
- 案例暱稱（The one with the pink box）建立品牌人格
- 極簡導航（三個圓點 + custom cursor）= 對作品價值的絕對自信
- 設計的終極目標不是好看，是有意義。Care is the work.
