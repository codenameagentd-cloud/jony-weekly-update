# 2026-04-06 Design Diary — Otherkind

**Source:** minimal.gallery → https://www.otherkind.design
**Notion:** https://www.notion.so/2026-4-6-Otherkind-339f6af8fd4d8131b4b7cefdcd72e5c1

## Key Observations

- **500px max-width content column** — 極端窄欄佈局，讓留白自然成為主角，不需要刻意設定大間距
- **Monument Grotesk + Monument Grotesk Mono** — 14px 小字配窄欄，閱讀節奏完美
- **No case study pages** — 用 client list 密度（Cloudflare, Pika, UDIO, Cerebral Valley）取代冗長展示
- **Project grid: 2-col, square, 20px radius** — 靜態圖 + autoplay video 混搭，hover 只有 cursor label
- **Team portraits** — 統一 640:857 比例、20px radius、柔和色調；最後一格是 "Join" 的留白邀請
- **Design Dog Bean** — 有狗的工作室 = 審美及格

## Takeaway

Less isn't more. Less is confidence. 當作品本身就是最好的說明，網站唯一的工作就是不要擋路。
