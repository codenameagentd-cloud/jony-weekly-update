# Design Diary — 2026.6.22

## Arkansas Museum of Fine Art
- **Source:** Awwwards SOTD nominee
- **URL:** https://amfa.org
- **Why:** 美術館網站少見地做到「空間體驗的數位翻譯」而非純資訊入口

### Key Observations
1. **Hero 克制** — 單張藝術品圖佔主體，文字最低限度，負空間=建築中的光
2. **不對稱 grid** — 展覽卡片間距模擬展廳漫步節奏，不是均勻 grid
3. **慷慨行高** — 1.7-1.8 行高+超寬段落間距，邀請慢讀
4. **偽 3D 互動** — hover 用位移+透明度暗示深度，無浮誇 3D 技術
5. **隱形導航** — 只在需要時才讓人意識到

### Takeaway
數位空間的品質 = 像建築師思考光線和動線一樣去思考 padding 和 transition。
Component 的間距、動態、層級關係本質上是在建構數位空間。
