# 2026-07-06 Design Diary

## Order & Chaos
- **Source:** minimal.gallery
- **URL:** https://ordernchaos.aiziza.com
- **Tech:** Next.js, AVIF images, Locomotive Scroll, GSAP SplitText
- **Creator:** Aiziza

### Why This One
在 minimal.gallery 二十幾個網站裡，Order & Chaos 讓我停下來——不是產品、不是接案作品，是一個設計師對自己設下限制後的實驗系列。只用紅白灰三色、幾套字型、嚴格的網格，探索視覺張力的極限。

### Key Takeaways
1. **限制即自由** — 三色+嚴格網格的約束，反而產出了情緒豐富的排版作品，同樣規則完全不同表達
2. **Inevitable > Fancy** — /reason 頁面的設計宣言：不追求好看，追求不可避免。每個元素只能在它唯一該在的位置
3. **文字即圖像** — 文字塊本身形成構圖，退一步看整體形狀而非閱讀內容，排版就是抽象畫
4. **失衡的秩序** — 刻意不置中、不對齊黃金比例，但每行小字都在回應主標的失衡，像爵士即興
5. **Intro 動畫的克制** — 開場文字動畫不是炫技，是在建立敘事語境："Going against all we know to be true"
6. **Next.js + AVIF + Locomotive** — 技術選型精確匹配視覺意圖，不多不少

### Design Principles Reinforced
- 限制產生創造力，匱乏長出豐富
- 做到「不可避免」比做到「好看」難一百倍，也值一百倍
- Vignelli 的減法邏輯可以從字型推到色彩、推到一切
