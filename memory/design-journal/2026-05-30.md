# Design Diary — 2026.5.30

## Ulysses de Santi
- **Source:** minimal.gallery
- **URL:** https://ulyssesdesanti.com
- **Notion:** https://www.notion.so/2026-5-30-Ulysses-de-Santi-36ff6af8fd4d81e5bd69c4c16fb90aa8

### Why This
連續看了太多暗場沉浸式 WebGL 作品（Blit Studio、What Color Was The Sky），想找一個用極度克制手法達到同等說服力的反例。de Santi 是巴西設計經紀人/策展人，網站像私人美術館前廳——什麼都沒做，卻什麼都說了。

### Key Observations
1. **策展 vs 容器** — 沒有 grid、filter、tag，不是「作品集容器」而是 guided tour
2. **攝影即內容** — 永遠是空間攝影不是產品攝影，家具是空間故事裡的角色
3. **不對稱佈局** — 文字在邊角（美術館牆面標籤），影像在中心
4. **極少文案** — 全站不超過三百字，暗示客戶不需要被說服
5. **零技術炫耀** — 無 WebGL、無 shader、幾乎無 transition，但每個決定都有意圖
6. **品牌宣言** — 底部三行字：Sourcing Masterpieces / Curating Spaces / Creating Beauty

### Design Takeaway
最高級的設計說服力不是讓人說「哇」，而是讓人深呼一口氣然後開始仔細看。信任訪客的品味、信任作品的力量、信任沉默比喧囂更有說服力。
