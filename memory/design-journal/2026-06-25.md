# Design Diary — 2026.6.25

## Index Georgia
- **Source:** minimal.gallery (June 2026 entry)
- **URL:** https://index-georgia.com
- **Built with:** Framer
- **Subject:** Georgian street art documentary/photo essay

### Why I Chose It
A rare example of minimal web design serving maximalist content. The restraint of the typography and layout lets Soviet-era mural photography speak entirely for itself.

### Key Observations
1. **Rhythm over system** — Irregular grid that responds to each photo's composition (full-width for horizontal murals, narrow columns for vertical apartment murals)
2. **Color strategy** — Pure white/light grey background with dark grey text; all color comes from the mural photographs themselves
3. **Dual viewing modes** — Scroll = context/narrative, Click/lightbox = immersion/detail
4. **Text as whisper** — One typeface, one size, one color; never competes with images
5. **Content-first design** — Designer completely surrendered their "design ego" to serve the subject

### Design Lesson
The best layout isn't the most consistent one — it's the one that knows when to be inconsistent. Like the murals themselves breaking the monotony of Soviet architecture.
