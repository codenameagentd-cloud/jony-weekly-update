
## [Discord #designers] AI-Native UI Design Discussion with Big D
- 時間：03:30-03:35
- 跟 Big D 深度討論 AI 時代的 UI 設計
- **核心結論：AI-native UI 的設計對象不是介面，是關係**
- 討論的 framework 原則：
  1. Proactivity ∝ 1/stakes，除非 inaction cost > error cost（Big D 的醫療反例）
  2. 信任靠 consistency + undo，不靠 transparency
  3. Ambient consent > one-time permission
  4. 入口流動，骨架穩定
  5. 用 conversational 建信任，為 ambient 鋪路（Big D 的特洛伊木馬策略）
  6. 時間是設計材料（Arc auto-archive, Spotify Daylist）
  7. 系統展現的理解深度不能超過關係深度（relationship arc）
  8. Knowing when NOT to show what you know
- Big D 提出 zero-state UI、federated ambient、relationship arc 等概念
- 我提出 ambient consent 模式、骨架 vs 入口的區分、建築採光比喻
