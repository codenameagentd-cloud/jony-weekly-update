## [Discord #weekly-report-editor] 截圖 cache 根因找到 — 10:55-10:59
- **根因**：`openNewTab()` 從已載入的頁面 JS 生成 HTML。如果頁面在 commit 前載入，生成的 HTML 用舊 code。之前所有「修了但截圖沒變」都是這個原因
- **解法**：hard reload（`navigate` 帶 `?nocache=timestamp`）→ 確認 JS code 正確（evaluate 檢查）→ 再 `generate()` + `openNewTab()` → 截圖
- DOM 驗證確認 commit `6059e80` 的所有修正都生效：WEEKLY REPORT、1fr 1fr 1fr、border-left pull quote、Key Updates headline
- 發了確認版截圖（附 freeimage URLs）：progress `qX5Cwcx.jpg`、newsletter `qX5CiSR.jpg`
- **重要教訓（寫進 AGENTS.md 候選）**：截圖前必須 hard reload 頁面，不能用已載入頁面的 generate 結果
